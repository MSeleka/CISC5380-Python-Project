# CISC5380-Python-Project

If you go into the Python Project Dataset Creation jupyter notebook, you will observe the process of creating the dataset necessary for the project.

The csv file tmdb_top_1000_movies.csv was used to provide the domestic revenue data; the data in this file was gathered using the tmdb API. This dataset was merged with data obtained from boxofficemojo to make the mereged_boxoffice_tmdb.csv file.
